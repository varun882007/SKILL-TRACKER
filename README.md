># Skill Tracker

A simple, responsive Skill Tracker website designed to help users organize their learning journey and visualize their skill development.

## About the Project

Skill Tracker is a frontend web development project built using HTML, CSS, and JavaScript. It features multiple pages with a clean interface designed to represent skill management and learning progress.

## Features

- Clean and user-friendly interface
- Multi-page website navigation
- Home page
- Skills page
- Progress page design
- About page
- Responsive styling and visual elements

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/varun882007/SKILL-TRACKER.git
   ```

2. Open the project folder in VS Code.

3. Open `Home.html` in your browser.
